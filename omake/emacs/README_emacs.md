# auximap.el - Emacs 連携（おまけ）

`auximap.exe` をバックエンドとして利用し、Emacs 上で IMAP メールの一覧取得、本文プレビュー、フォルダ切り替え、マーク操作等を行うための連携スクリプトです。

> **位置づけ**: 本スクリプトは有志による連携機能のおまけ（参考実装）です。
> パスワードが `auximap.ini` に記述されていない場合は、初回アクセス時にミニバッファでマスク入力（`***`）を求められ、Emacs のメモリ内に一時保持されます。
> 本格的なメールソフトのように高度な暗号化処理によるプライバシー保護は考慮していません。多数のユーザーがアクセスする環境では使用しないでください。

---

## 前提条件

1. `auximap.exe` が実行可能な状態にあること（環境変数 PATH、または Emacs の実行ファイルディレクトリ等に配置）。
2. `auximap.ini` にアカウント情報が記述されていること（`pass = ` は空欄で動作可能）。

---

## 導入方法（init.el）

お使いの `init.el` または `.emacs` に以下を記述します。

### 1. 基本的な設定例
```elisp
;; auximap.el の配置フォルダを load-path に追加
(add-to-list 'load-path "~/.emacs.d/lisp")

(require 'auximap)

;; auximap.exe のパス（PATH が通っている場所や bin/ にある場合は自動検出されます）
;; (setq auximap-program "C:/path/to/auximap.exe")

;; デフォルトのアカウント名（省略時は auximap.ini の最初のアカウントを自動検出）
;; (setq auximap-default-account "your_account")

;; デフォルトのフォルダ（省略時は "INBOX"）
(setq auximap-default-folder "INBOX")

;; 左右分割（既定: 'vertical。上下分割にする場合は 'horizontal）
(setq auximap-window-split-direction 'vertical)

;; F9 キーでトグル（開く／閉じる）
(global-set-key (kbd "<f9>") 'auximap-toggle)
```

### 2. use-package を使う場合
```elisp
(use-package auximap
  :load-path "~/.emacs.d/lisp"
  :bind ("<f9>" . auximap-toggle)
  :custom
  ;; (auximap-default-account "your_account") ; 省略時は auximap.ini の最初のアカウント
  (auximap-default-folder "INBOX")
  (auximap-window-split-direction 'vertical))
```

## 画面構成と機能

### 画面レイアウト
標準では左右2画面（左がメール一覧、右が本文プレビュー）で起動します。
上下2画面に変更したい場合は `(setq auximap-window-split-direction 'horizontal)` を設定します。

### フォルダの確認と切り替え
- **フォルダバー**: メール一覧の上部に各フォルダ（`[INBOX]` `[Trash]` 等）がボタンとして並びます。マウスでのクリック、またはボタン上で Enter を押すと該当フォルダが開きます。
- **Ilist / Imenu 連携**: `i` キーを押すか、`imenu-list` バッファ（`*Ilist*`）を開くことで、フォルダ一覧とメール一覧が階層ツリー状に表示されます。ツリー上のフォルダ名を選択すると該当フォルダへ切り替わります。

---

## 操作方法

Emacs 上で `M-x auximap`（または設定した `<f9>`）を実行するとメーラーが起動します。起動のたびに、メール一覧をサーバーから取得します。

### ナビゲーション・閲覧
| キー | 動作 |
| :--- | :--- |
| `<f9>` | メーラーの開く／閉じるをトグル |
| `n` / `j` / `↓` / `C-n` | 次のメールへ移動＆本文プレビュー |
| `p` / `k` / `↑` / `C-p` | 前のメールへ移動＆本文プレビュー |
| `RET` (Enter) | 本文バッファにフォーカスを移動（ボタン上では該当動作） |
| `Tab` / `S-Tab` | 本文プレビューのスクロール（下／上） |
| `v` | カーソル位置のメール本文を再読込（強制取得） |
| `P` | 自動プレビューの ON/OFF 切替 |
| `r` / `g` | メール一覧をサーバーから再取得（リロード） |
| `i` | Imenu 呼び出し（Ilist との連携、フォルダ一覧・メール選択） |
| `f` / `c` | フォルダ切り替え（ミニバッファ補完から選択） |
| `a` | アカウント切り替え（ミニバッファ補完から選択） |
| `q` / `<f9>` | 終了（元のウィンドウ構成に戻る） |
| `<f1>` / `?` / `h` | 操作ガイドのポップアップ表示 |

### マーク・一括操作・削除
| キー | 動作 |
| :--- | :--- |
| `t` | カーソル行のマークを反転（トグル） |
| `d` | カーソル行に削除マーク（`D`）を付けて次行へ |
| `u` | カーソル行のマークを解除して次行へ |
| `C-a` / `U` | すべてのマークを解除 |
| `T` | 全メールのマーク反転 |
| `% m` / `m` | キーワードで一括マーク |
| `% d` | キーワードで一括削除マーク（`D`）を付与 |
| `% u` | キーワードで一括マーク解除 |
| `/` | キーワードで絞り込みフィルタ（空Enterまたは `//` で解除） |
| `x` / `D` | マークされたメールをゴミ箱へ移動（y/n 確認付き） |

※`SPC` キーは Meow 等のリーダーキーと共存するため未バインドです。

## パスワードの管理

- `auximap.ini` の `pass = ` が空欄の場合、初回アクセス時にミニバッファでパスワードの入力（`***` でマスク）を求められます。
- 入力されたパスワードは Emacs のプロセス内（メモリ）に保持され、ファイル等には保存されません。Emacs を終了すると消去されます。
- パスワードを再入力したい場合は、`M-x auximap-clear-auth` を実行してキャッシュをクリアしてください。
- 起動時の一覧取得でパスワードを求められた場合、`C-g` で入力を中断できます。中断後も一覧画面は開いたままなので、`a` でアカウントを切り替えると、選んだアカウントのパスワードを求められます。

---

## キャッシュについて

メール一覧は起動時に毎回サーバーから取得します。一覧のキャッシュ表示は行いません。

一度取得したメール本文はローカルの一時ディレクトリにキャッシュされます。キャッシュが存在するメールはサーバーへの再アクセスを行わずに表示します。最新の本文を再取得したい場合は `v` キーを押してください。
